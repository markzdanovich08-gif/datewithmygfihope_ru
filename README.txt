РОМАНТИЧЕСКОЕ SPA — ИНСТРУКЦИЯ

1) Локально
- Распакуй проект.
- Открой index.html в браузере, чтобы посмотреть интерфейс. Отправка в Telegram локально не заработает без Netlify Functions.
- Для корректной проверки функции используй Netlify CLI (`netlify dev`) или тестовый деплой.

2) Фотографии
- Положи свои файлы в папку images с именами photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg.
- Если фотографий нет, вместо них будут видны цветные градиенты.
- Не используй фотографии другого человека без разрешения.

3) Telegram-бот
- В Telegram найди @BotFather и отправь /newbot.
- Следуй подсказкам. BotFather выдаст токен. Не публикуй его и не вставляй в script.js.
- Открой чат с ботом и нажми Start (или отправь ему любое сообщение).
- Чтобы получить chat_id личного чата, открой в браузере:
  https://api.telegram.org/botТВОЙ_ТОКЕН/getUpdates
  Замени ТВОЙ_ТОКЕН своим токеном. В JSON найди "chat":{"id":123456789...}; это chat_id.
  Если updates пустой, отправь боту сообщение и обнови страницу.
- Токен из URL — секрет: не пересылай этот URL другим и не публикуй скриншоты с токеном.
- Если нужно отправлять в группу, добавь туда бота и получи ID группы отдельно.

4) Деплой на Netlify
- Открой https://app.netlify.com/ и войди/создай аккаунт.
- Самый простой drag-and-drop деплой поддерживает статические файлы, но для Netlify Functions надёжнее подключить папку проекта через Git:
  a) Создай репозиторий GitHub и загрузи туда все файлы проекта.
  b) В Netlify нажми Add new site → Import an existing project → GitHub и выбери репозиторий.
  c) Build command оставь пустым, Publish directory укажи ".". Файл netlify.toml уже задаёт папку функций.
  d) После деплоя открой Site configuration / Environment variables (название раздела может немного отличаться).
  e) Добавь TELEGRAM_BOT_TOKEN = токен от BotFather и TELEGRAM_CHAT_ID = свой chat_id.
  f) Запусти новый deploy, чтобы функция получила переменные окружения.
- Drag-and-drop папки на https://app.netlify.com/drop годится для предпросмотра статической части, но не следует рассчитывать на работу серверной функции в таком деплое. Для отправки Telegram используй Git deploy с Netlify Functions.

5) Проверка
- Открой опубликованный сайт, пройди все экраны и нажми «Подтвердить выбор».
- Проверь Telegram. Если не пришло сообщение, посмотри Function logs в Netlify и убедись, что бот уже получал сообщение от тебя.
- Никогда не коммить токен в GitHub и не помещай его в публичный JavaScript.
